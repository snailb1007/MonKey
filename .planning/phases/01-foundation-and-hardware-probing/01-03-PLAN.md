# Phase 1 Plan 03: monkey-cli Integration (info and probe), Formatted/JSON Output, and Headless Integration Tests

**As a** keyboard user or developer, **I want to** discover and probe my Monka 3075 Pro over USB HID, **so that** I can verify device identity and connection health without triggering OS security prompts.

<objective>
Implement the standalone binary crate `crates/monkey-cli` providing user-facing inspection commands `monkey info` and `monkey probe`. Support both human-readable terminal tables and machine-readable structured JSON output (`--json`). Implement automated headless integration tests verifying CLI command execution and JSON schema compliance against `MockTransport` with zero flash commits.

Purpose: Provide keyboard users and CI automation with an ergonomic, safe command-line interface to inspect Monka 3075 Pro hardware attributes without administrative prompts or risk of firmware corruption.
Output: Complete `monkey-cli` binary with `info` and `probe` subcommands, output formatters, and automated headless integration test suite.
</objective>
