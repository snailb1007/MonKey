# 05-02: Shell Completion Generation (`monkey completions <shell>`)

## Objective
Implement shell autocompletion generation using `clap_complete` for `bash`, `zsh`, `fish`, `elvish`, and `powershell`. Allow users and package maintainers to emit scripts directly to stdout for shell sourcing and package installation.

## Proposed Changes
1. **Dependencies**:
   - Add `clap_complete = "4.6"` to root `Cargo.toml` and `crates/monkey-cli/Cargo.toml`.
2. **`crates/monkey-cli/src/commands/completions.rs`**:
   - Define `ShellChoice` enum (Bash, Zsh, Fish, Elvish, PowerShell) implementing `ValueEnum`.
   - Implement `run_completions(shell: ShellChoice)` which calls `clap_complete::generate` with the `Cli::command()` CLI struct.
3. **`crates/monkey-cli/src/commands/mod.rs` & `main.rs`**:
   - Register `completions` subcommand.
4. **Integration Tests**:
   - `crates/monkey-cli/tests/cli_completions_test.rs`:
     - Test generation for each supported shell (`bash`, `zsh`, `fish`, `elvish`, `powershell`).
     - Assert generated completion scripts contain `monkey` command names and subcommands (`info`, `probe`, `bench`, `lcd`, `rgb`, `doctor`, `completions`).

## Verification
- `cargo test --test cli_completions_test`
- Run `cargo run -p monkey-cli -- completions zsh` and verify valid Zsh completion syntax.
