# 05-01: System Diagnostics and Remediation Engine (`monkey doctor`)

## Objective
Implement `monkey doctor` subcommand in `monkey-cli` and supporting diagnostic probe utilities in `monkey-core` to inspect OS platform, USB HID subsystem, device detection across Interface A and Interface B, permission accessibility (macOS Input Monitoring / Linux udev), and provide actionable remediation instructions.

## Proposed Changes
1. **`crates/monkey-core/src/device.rs` or `crates/monkey-core/src/doctor.rs`**:
   - Define diagnostic check structs:
     - `CheckStatus`: `Pass`, `Warn`, `Fail`.
     - `DiagnosticCheck`: `id`, `name`, `status`, `message`, `remediation: Option<String>`.
     - `DoctorReport`: system platform info, list of checks, summary counters, overall healthy boolean.
   - Implement diagnostic evaluator `run_doctor_checks`:
     - Platform check (macOS version / sandbox detection).
     - HID subsystem check (`hidapi` initialized).
     - Keyboard enumeration check (identifies Monka 3075 Pro / RKGK890, connection type: wired vs wireless).
     - Interface A check (opens bulk pipe `0xFF68:0x61`).
     - Interface B check (opens control pipe `0xFFFF:0x0001`, probes feature report accessibility).
     - Remediation engine providing specific macOS and Linux instructions.
     - Mock support (`--mock`) generating synthetic clean diagnostic reports for headless testing.
2. **`crates/monkey-cli/src/commands/doctor.rs`**:
   - `DoctorArgs` with `--mock` and `--json`.
   - Formatted human output with check marks (`[✓] PASS`, `[!] WARN`, `[✗] FAIL`) and remediation callout box.
   - JSON output matching `DoctorReport` schema.
3. **`crates/monkey-cli/src/commands/mod.rs` & `main.rs`**:
   - Register `monkey doctor` in CLI command hierarchy.
4. **Integration Tests**:
   - `crates/monkey-cli/tests/cli_doctor_test.rs`: test `--mock` execution, JSON serialization, remediation messages, and failure handling.

## Verification
- `cargo test --test cli_doctor_test`
- Run `cargo run -p monkey-cli -- doctor --mock` and `cargo run -p monkey-cli -- doctor --mock --json`
