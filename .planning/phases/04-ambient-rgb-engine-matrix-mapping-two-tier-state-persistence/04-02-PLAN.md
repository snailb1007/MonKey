# Plan 04-02: Two-Tier State Manager, Flash Wear Debouncing, Low-Battery Safety Gate & Profile Serialization

## Objective
Implement `RgbManager` orchestrating volatile RAM preview vs debounced flash commit, enforce low-battery safety gating on wireless connections, and provide JSON profile serialization, restore, and readback verification.

## Proposed Changes

### `crates/monkey-core/src/rgb/profile.rs`
- Define `RgbProfile` struct with `schema_version`, `model`, `created_at`, `lighting: LightingConfig`, and optional description.
- Implement JSON serialization (`to_json`) and deserialization (`from_json`) with version validation.
- Provide helper methods to write to and read from disk safely.

### `crates/monkey-core/src/rgb/manager.rs`
- Implement `RgbManager` wrapping `Transport` and `SafetyRails`.
- Implement `apply_preview(config: &LightingConfig)`:
  - Sends `04 13` over Interface B with `WriteMode::RamPreview`.
  - Rate-limited up to 30Hz; skips flash commit entirely.
- Implement `apply_commit(config: &LightingConfig, force: bool)`:
  - Checks transport state and battery level. If wireless and battery < 20%, returns `BatteryTooLowForFlashCommit` error unless `force` is true.
  - Enforces 500ms debounce window via `SafetyRails`.
  - Sends transaction: `04 18` -> `04 13` -> `04 02` -> `04 F0`.
  - Increments session flash commit counter.
- Implement `readback_status()`:
  - Sends `04 F5` query report to verify device lighting state.
- Implement `save_profile(path: &Path)` and `restore_profile(profile: &RgbProfile, commit: bool, force: bool)`.

### `crates/monkey-core/tests/rgb_manager_test.rs`
- Integration tests with `MockTransport`:
  - Verify `apply_preview` emits single `04 13` packet without transaction wrappers or save opcode.
  - Verify `apply_commit` emits full transaction sequence (`04 18`, `04 13`, `04 02`, `04 F0`).
  - Verify 500ms flash debounce blocks rapid back-to-back commits.
  - Verify low battery (< 20%) on wireless blocks commit unless forced.
  - Verify profile save, restore, and readback verification.
