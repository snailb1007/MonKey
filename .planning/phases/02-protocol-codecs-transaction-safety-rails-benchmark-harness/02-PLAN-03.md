# Plan 03: Synthetic Benchmark Harness & CLI bench Command

## Goal
Implement a hardware-isolated synthetic benchmark engine measuring bulk transfer throughput (simulating 8x4096-byte LCD frames at target 10-15 FPS) and command transaction latency, exposed via the `monkey bench` CLI command.

## Tasks
1. Implement `crates/monkey-core/src/bench/mod.rs`:
   - `BenchmarkConfig` (duration, frame count, chunk size, target fps).
   - `ThroughputReport` (total_bytes, elapsed, bytes_per_sec, frames_per_sec).
   - `LatencyReport` (samples, min_us, max_us, avg_us, p95_us).
   - Benchmark runners over `Transport` trait:
     - `run_bulk_streaming_bench(transport, config)`
     - `run_transaction_latency_bench(transport, config)`
2. Export bench module in `crates/monkey-core/src/lib.rs`.
3. Implement `crates/monkey-cli/src/commands/bench.rs`:
   - CLI args: `--type <bulk|transaction|all>`, `--duration-secs <u64>`, `--frames <usize>`, `--mock`, `--json`.
   - Visual progress indicator using `indicatif`.
   - Formatted human output and JSON serialization.
4. Wire `Bench` command into `crates/monkey-cli/src/commands/mod.rs` and `main.rs`.
5. Author test suite in `crates/monkey-cli/tests/cli_bench_test.rs` testing mock benchmark execution, output formatting, and metrics calculation.

## Verification
- `cargo test --test cli_bench_test` passes.
- `cargo run -p monkey-cli -- bench --mock --json` emits valid JSON throughput and latency metrics.
- `cargo run -p monkey-cli -- bench --mock` displays formatted benchmark metrics cleanly.
