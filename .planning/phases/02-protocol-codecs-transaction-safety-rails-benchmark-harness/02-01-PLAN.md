# Plan 01: Shenzhen HFD Protocol Codecs & Checksum Verification

## Goal
Implement domain-specific zero-copy codecs for Shenzhen HFD protocol commands (RGB command 0x13, Matrix lighting 0x20, Keymap 0x11, Readback 0xF5, Lifecycle commands 0x18/0x02/0xF0) and checksum verification algorithms (CRC16 and XOR).

## Tasks
1. Add `crc = "3.4.0"` to `crates/monkey-core/Cargo.toml`.
2. Expand `crates/monkey-core/src/error.rs` with `ProtocolError` variants (e.g. `InvalidMagic`, `InvalidMarker`, `ChecksumMismatch`, `UnknownCommand`, `BufferOverflow`).
3. Implement `crates/monkey-core/src/protocol/checksum.rs` with CRC16 (CCITT, MODBUS, ARC) and XOR checksum helpers.
4. Implement `crates/monkey-core/src/protocol/codec.rs` providing high-level typed builders and parsers for:
   - Built-in RGB mode command packet (`0x13`)
   - RGB matrix lighting packets (`0x20`)
   - Keymap configuration packets (`0x11`)
   - Readback request and response packets (`0xF5`)
   - Bulk chunk frame formatting for Interface A.
5. Export types in `crates/monkey-core/src/protocol/mod.rs`.
6. Author comprehensive tests in `crates/monkey-core/tests/protocol_codec_test.rs` testing serialization, deserialization roundtrips, invalid magic/marker rejection, and checksum verification.

## Verification
- `cargo test --test protocol_codec_test` passes cleanly.
- Zero-copy layout matches 64 bytes for feature reports and 4096 bytes for bulk chunks.
