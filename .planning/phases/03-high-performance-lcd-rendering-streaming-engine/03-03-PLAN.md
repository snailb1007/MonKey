# Plan 03-03: Image Loading, GIF Player Loop & CLI Integration

## Objective
Implement static image preprocessing (auto-crop, resize to 128x128), animated GIF decoding and streaming with frame delay scheduling, and wire everything into `monkey-cli` under `monkey lcd` subcommands with `indicatif` progress feedback.

## Proposed Changes

### `crates/monkey-core/src/lcd/image_loader.rs`
- Helper to load image from file path or memory buffer.
- Center-crop and downscale to 128x128 pixels using `CatmullRom` or `Lanczos3` filter.
- Helper to decode multi-frame GIF via `GifDecoder`, extracting frame delays and converting frames to RGB565.

### `crates/monkey-cli/src/commands/lcd.rs`
- Subcommand `monkey lcd image <path> [--dither] [--big-endian]`:
  - Loads, resizes, converts image to RGB565.
  - Sends 8 chunks with progress bar.
- Subcommand `monkey lcd test-pattern <pattern> [--big-endian]`:
  - Generates Red, Green, Blue, White, or Grayscale ramp test pattern.
  - Sends to LCD to visually calibrate color channels and byte order.
- Subcommand `monkey lcd anim <path> [--fps <N>] [--dither] [--loop]`:
  - Decodes GIF frames.
  - Runs animated streaming loop paced at GIF frame delays or specified target FPS.
  - Handles SIGINT (Ctrl-C) gracefully.

### `crates/monkey-cli/src/args.rs` & `commands/mod.rs`
- Register `LcdArgs` and `LcdCommand` variants in CLI argument parser.

## Verification
- Unit and integration tests for image loading, resizing, and test-pattern generation.
- CLI subcommand tests validating argument parsing and mock execution.
