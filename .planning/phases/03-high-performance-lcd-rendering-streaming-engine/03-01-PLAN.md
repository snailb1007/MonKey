# Plan 03-01: RGB565 Color Conversion & Dithering Engine

## Objective
Implement high-performance zero-allocation RGB565 color quantization with optional serpentine Floyd-Steinberg error diffusion dithering (<15ms processing time for 128x128 buffer) and configurable endianness, along with synthetic test patterns for byte-order verification.

## Proposed Changes

### `crates/monkey-core/src/lcd/color.rs`
- Define `ColorFormat` enum or config (Little-Endian, Big-Endian).
- Implement `rgb888_to_rgb565(r: u8, g: u8, b: u8) -> u16`.
- Implement `rgb565_to_bytes(pixel: u16, little_endian: bool) -> [u8; 2]`.
- Provide pure diagnostic colors: Red (`0xF800`), Green (`0x07E0`), Blue (`0x001F`), White (`0xFFFF`), Black (`0x0000`).

### `crates/monkey-core/src/lcd/dither.rs`
- Implement Floyd-Steinberg error diffusion dithering on 128x128 RGB888 image buffer producing a 32,768-byte RGB565 byte buffer.
- Use serpentine scanning (alternating left-to-right and right-to-left rows) to minimize worm artifacts.
- Benchmark and verify latency is strictly <15ms.

### `crates/monkey-core/src/lcd/mod.rs`
- Expose color and dithering modules.
- Re-export high-level helper `convert_image_to_frame(image: &RgbImage, dither: bool, little_endian: bool) -> [u8; 32768]`.
- Expose `generate_test_pattern(pattern_type: TestPatternType) -> [u8; 32768]`.

## Verification
- Unit tests validating exact byte values for pure red, green, blue under Little-Endian and Big-Endian.
- Latency benchmark test asserting conversion + dithering completes in <15ms.
