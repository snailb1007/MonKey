# Plan 03-02: Frame Chunker, Inter-Chunk Pacing & Flow Control

## Objective
Implement zero-copy slicing of the 32,768-byte frame into 8 contiguous 4096-byte OUT chunks targeting Interface A (`0xFF68`), microsecond-accurate inter-chunk pacing (3ms–8ms), and frame rate regulation (10–15 FPS) with non-blocking backpressure frame drops.

## Proposed Changes

### `crates/monkey-core/src/lcd/chunker.rs`
- Define `FrameChunker` iterator or slice helper dividing a 32,768-byte buffer into 8 chunks of 4096 bytes each.
- Assert chunk count == 8 and each chunk length == 4096.

### `crates/monkey-core/src/lcd/streamer.rs`
- Implement `LcdPacingConfig` (`inter_chunk_delay: Duration`, `target_fps: u32`).
- Implement `LcdStreamer`:
  - Takes a `Transport` reference or hardware channel.
  - `send_frame(&mut self, frame: &[u8; 32768]) -> Result<(), TransportError>`:
    - Iterates over the 8 chunks.
    - Sends each chunk using `transport.write_bulk(chunk)`.
    - Sleeps for `inter_chunk_delay` between chunks.
  - Measures total transmission time and reports metrics (asserting <50ms target when delay is 3ms).
- Implement `FpsRegulator`:
  - Enforces loop interval corresponding to target FPS (e.g., ~83.3ms for 12 FPS).
  - Skips or drops frames if processing/transfer overshoots deadline.

## Verification
- Unit test using `MockTransport` asserting exactly 8 calls to `write_bulk` with 4096 bytes each.
- Integration test measuring inter-chunk timing pacing and total frame transfer time.
