# Phase 6 Plan 01: Pure Transport Trait & SafeTransport Guard Façade (Wave 1)

**As a** developer and driver architect, **I want to** decouple low-level byte transport adapters from domain protocol safety logic and introduce a centralized `SafeTransport` guard façade, **so that** byte adapters have zero domain awareness while write authorization remains strictly enforced at compile time.

<objective>
Eliminate domain leakage from low-level byte adapters (`HidTransport`, `MockTransport`, `RecordingTransport`) by removing `&SafetyRails` from the `Transport` trait. Introduce the `SafeTransport<'a>` RAII guard façade wrapping `(&'a mut dyn Transport, &'a SafetyRails)` to centralize `validate_hardware_write_permitted()` checks. Adapt `TransactionManager`, `HardwareChannel`, `LcdStreamer`, and `RgbManager` to consume `SafeTransport<'a>`, preserving compile-time write authorization guarantees.
</objective>

    Implement the `SafeTransport<'a>` guard façade per decision D-07 in `crates/monkey-core/src/transport/safe.rs`:
    - Define `pub struct SafeTransport<'a> { transport: &'a mut dyn Transport, safety: &'a SafetyRails }`.
    - Implement `SafeTransport::new(transport: &'a mut dyn Transport, safety: &'a SafetyRails) -> Self`.
    - Implement `reborrow<'b>(&'b mut self) -> SafeTransport<'b>` allowing sub-managers to borrow the underlying transport and safety references without losing ownership.
    - Implement `write_bulk(&mut self, report_id: u8, data: &[u8]) -> Result<usize, TransportError>`: centrally check `self.safety.validate_hardware_write_permitted().map_err(|e| TransportError::ProtocolViolation(e.to_string()))?` before delegating to `self.transport.write_bulk(report_id, data)`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Domain Logic → Hardware Transport | Protocol operations requesting raw byte writes to USB endpoints |
| Byte Adapter → OS HID / Mock Buffer | Untrusted / raw data passed to kernel or test recording structures |
| Multi-caller write paths → Hardware | Concurrent write callers (`LcdStreamer`, `TransactionManager`) reaching physical endpoints |
