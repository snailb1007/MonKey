# Phase 6 Plan 03: CLI Migration, Env-Var Hack Eradication, and Test Seam Unification (Wave 3)

**As a** user and CLI developer, **I want to** migrate all CLI subcommands (`info`, `probe`, `lcd`, `rgb`, `bench`, `doctor`) to the unified `MonkaDevice` abstraction, eliminate production environment variable hacks, and unify fragmented test seams, **so that** CLI hardware interactions are predictable, cohesive, and maintainable.

<objective>
Refactor all six CLI commands to acquire hardware handles exclusively through `MonkaDevice::open(policy)` or `MonkaDevice::from_transport(mock)` for `--mock` execution. Eradicate `std::env::var("MONKEY_SIMULATE_EMPTY")` from `info.rs` and `probe.rs`. Eliminate five fragmented ad-hoc test seams (`run_probe_with_transport`, `run_bench_with_transport`, `run_info_with_device_set`, `resolve_transport`, `stream_one`), while guaranteeing full POSIX exit code fidelity.
</objective>
