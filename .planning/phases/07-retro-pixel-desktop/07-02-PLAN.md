# 07-02 — Retro pixel desktop vertical UI and full regression gate

## Objective / ownership
Build the complete usable frontend over approved 07-01 native IPC. Own ONLY apps/desktop/** EXCEPT src-tauri/** and contracts/**, plus this plan's SUMMARY. Includes package.json/pnpm-lock, Vite/TS/ESLint/Vitest/Playwright configs, src, public original assets, browser fixtures and app README. Do not change root Cargo files, core/CLI, native files, shared IPC fixtures or sibling SUMMARY. Native bugs/contracts requiring changes must return to native owner through a separate replan/fix card, not an ownership bypass. Use parent-approved branch as base so backend is physically present; parent completion alone does not merge git branches.

## Required context / shared decisions
Read 07-UI-SPEC.md, 07-CONTEXT.md, 07-RESEARCH.md and parent 07-01-SUMMARY before starting. No existing docs/solutions pattern was found by Scout. Only invoke desktop_request({request}); version 1 camelCase envelopes, snake_case actions list_devices/probe/diagnostics/pick_asset/start_lcd/stop_lcd/job_status/rgb_status/rgb_preview/rgb_commit/export_profile/import_profile. Mirror typed DTOs and verify against backend-owned contracts/ipc-v1.json fixtures (including invalid payload cases); do not change native contract. A 0xFF68:0x0061 is LCD, B 0xFFFF/config is RGB; honor capability booleans and backend errors, never infer capabilities or invent numeric ranges. Remap/macro/firmware disabled; no arbitrary file paths/opcodes/shell command. Serialized native worker owns I/O. Preview is RAM-only <=30Hz; explicit save-to-device is separate from export profile; backend controls debounce/readback/battery gate. Mock/demo is explicit and permanently labeled, not automatic fallback.
React+TypeScript+Vite, pnpm exact packageManager and committed lockfile. Plain CSS, no external fonts/CDN/UI megaframework. UI-SPEC palette, 4px spacing, square edges/pixel glyphs and readable 14–16px system sans with Vietnamese support. Device/LCD/Lighting/Diagnostics nav, native titlebar, 1040x720 minimum 760x560. Unknown/loading/error/disconnected/asleep/partial-interface states and visible disabled reasons are first-class.

## Tasks
1. Create reproducible frontend harness and an actual Device vertical tracer: typed bridge with real Tauri invoke and separately injected demo adapter; browser demo/e2e cannot open hardware. Device discovery -> selection -> probe renders snapshot/error states. Typecheck and tests fail before implementing stale response/device switching protections. Verify fixtures from parent directly, not independent hand-maintained fake contract. End-to-end first passes Device path before screen expansion.
2. Build accessible shell/design tokens and original pixel icons; Device capability reference explains unsupported OEM functionality. Add keyboard skip/nav/focus flow, semantic labels, text statuses, reduced-motion handling and responsive stacked layout. No decorative animation or unreadable bitmap body type.
3. Implement LCD chooser, actual converted preview, image/GIF/sequence/pattern flows, progress polling <=4Hz, start/stop/busy handling, file cancellation and validation recovery. Handle unplug, delayed request and stale-job completion. Preview/send labels must distinguish local preview from hardware success.
4. Implement Lighting current readback, mode/ranges/color/direction from native supported values, bounded/coalesced RAM previews, clear unsaved state and explicit Save to device confirmation. Import validates then previews only on consent; export is local file action. Show battery/unknown/permission failure and readback success without pretending a failed save succeeded. Never persist due to slider, navigation or unload.
5. Implement Diagnostics grouped pass/warn/fail/unknown and recovery, sanitized copy, CLI benchmark/completion guidance with explicitly deferred desktop parity. No raw serial/device/file paths in report. Add actionable empty/no-device and explicit demo banner throughout.
6. Add Vitest/Testing Library tests for every screen state, fixture shape, unknown values, capabilities, no unsafe invokes, duplicate operations, throttle/cancel/dispose, request races and errors. Add Playwright desktop.spec.ts with injected IPC demo for Device/LCD/Lighting/Diagnostics, mocked native picker cancel/error, empty/partial/asleep/permission/low battery/unplug/busy, keyboard-only dialogs and stop, reduced motion, narrow layout and 200% zoom equivalent. Use @axe-core/playwright; assert no serious/critical violations on all four pages and key dialogs. Check text contrast separately where axe cannot evaluate. Tests must not depend on absence of future feature modules.
7. Establish scripts: dev (Vite 127.0.0.1 port 1420 strictPort), build (tsc + vite build), typecheck, lint (no fix), test:unit (Vitest run), test:e2e (Playwright), desktop:build (`tauri build --no-bundle`). Playwright starts its own local Vite server with explicit demo mode and no arbitrary exposed invoke. Document install/dev/build and demo vs physical-device behavior in apps/desktop/README.md. Capture actual screenshot artifacts for four pages and key failure states; no fabricated screenshots or hardware timing claims. Production Tauri build is final gate, unsigned and unbundled. Use exact node/pnpm versions recorded in README and packageManager. Install dependencies/browser engines as setup, not from read-only test scripts.
8. Format only owned changes; run all exact gates below (frontend production build/full regression once at final handoff). Write SUMMARY from $HOME/.hermes/gsd-core/templates/summary.md, commit with code, hand off to independent Reviewer with head_sha, branch/base, test_evidence/log paths/screenshots/findings/ready_for_ce_compound. Any unavailable native build dependency is a blocker, not permission to skip a gate. Human hardware UAT remains after integration.
